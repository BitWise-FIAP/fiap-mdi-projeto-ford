## 📌 Sobre o Projeto

O **Ford VINculo** é um aplicativo mobile desenvolvido para melhorar a experiência do cliente da Ford, centralizando em um único aplicativo informações, veículos, agendamentos, recompensas e suporte inteligente.

### 🎯 Objetivo

Desenvolver uma solução mobile moderna, intuitiva e acessível para facilitar o relacionamento do cliente com a marca e oferecer uma experiência mais completa dentro e fora do veículo.

---

## ⚙️ Funcionalidades

- Tela de boas-vindas
- Cadastro e login de usuários
- Modo visitante
- Home principal
- Cadastro e visualização de veículos
- Comparação de veículos com Inteligência Artificial
- Agendamento de serviços
- Histórico de serviços
- Sistema de recompensas
- Perfil do usuário
- Configurações do aplicativo
- Suporte e dúvidas frequentes
- Interface responsiva e moderna

---

## 🧰 Tecnologias

- React Native
- Expo
- JavaScript
- Expo Router
- AsyncStorage
- API da Groq
- Modelo de IA para comparação e recomendação de veículos

---

## 🤖 Inteligência Artificial

O aplicativo utiliza a API da Groq para realizar comparações entre veículos e oferecer recomendações personalizadas de acordo com as necessidades do usuário.

A chave da API não é incluída no projeto. Para testar a funcionalidade da IA, é necessário configurar a variável `EXPO_PUBLIC_GROQ_API_KEY`.
